# CHSH 偏振纠缠 · 3D 仿真实验室

网页入口：https://hzz794591-ctrl.github.io/quantum-chsh-lab/

使用 Edge / Chrome 等支持 WebGL 的浏览器访问。所有计算在访问者自己的浏览器中进行，网站由 GitHub Pages 托管。

## 操作

- 默认进入“引导装配”。器件库中共有 27 件器件，左右两侧各有一台可安装的符合计数设备；沿用原左侧设备的装配记录。
- 第 3 号入射半波片使用与第 6 号四分之一波片相同的圆形镜架，仍保留半波片身份和入射光路朝向。移除桌面最前方的两条白色线缆，接收器仅向各自侧台连接。
- 点击器件，查看作用、安装位置及模型说明；对应安装位会高亮，点击安装标记或台面光圈即可安装。
- 支持分类、搜索、下一件、定位、拆下、重新装配；进度保存在当前浏览器本地，不上传服务器。
- 手机端选中器件后显示详情，可用左上角返回按钮回到器件库。
- 在库中选中 A / B 测量臂的半波片，即可在安装前填写四次实验各自的 A / B 机械角，共四行、八个数值；装配和完整实验共用设置，并保存在当前浏览器。切换装配预览不会改变待采集的组。
- 完整实验按四组进行：装配时预设角度 → 逐组调节并采集 → 每完成一组记录一个 E → 四组齐全后显示实验 S。
- 不设目标角度、不要求匹配或确认角度。进入首组或下一组会读入装配时为该组填写的角度，可直接采集，也可用数字输入或滑块改成任意有效角度再采集。只校验数值有效且位于 −90° 至 90°。固定偏振片为 0° 时，分析角为机械角的 2 倍。
- 默认最大违背示例的四对机械角为 (0°,11.25°)、(0°,33.75°)、(22.5°,11.25°)、(22.5°,33.75°)，不作为必须达到的目标。首组开始后，装配配置、模式与统计参数锁定；每个待测组的当前角度仍可修改。采集开始时锁定本组实际角度，已记录的 E 不会被后续调节改写。
- 理论 E / S 放在默认折叠的“理论预测 · 非实测结果”中，不作为实验结果。修改装配配置会进入随机模拟；标准模拟中临时修改当前角度时，该组按实际角度独立模拟，不套用其他角度的参考计数。每组记录参考或模拟来源，混合运行会明确标记。
- “完整实验”进入预先装好的实验场景；切换不会清空装配进度。采集进行中或暂停时不可进入装配。
- W / A / S / D：移动观察视角；Q / E：降低 / 升高。
- 右键拖动：转向；滚轮：靠近 / 远离；R：返回全景。
- 点击“采集第 N 组”仅采集该组的四个符合计数并记录一个 E，随后停止；点击“下一组”后可直接采集或再改角度。未齐四组时显示“已完成 N/4 组，S 待计算”。“重新测量”需要确认，清空旧计数、E 和 S，但保留四组装配配置与装配进度。
- 四组齐全后才计算实验 S、生成完整图表并启用 CSV / JSON / SVG 导出。组间可在记录表和“数据与图表”中查看已经完成的 E 与计数。
- 点击图表中的变量、图形、表头或数值，查看含义、公式与本次数值；点击标题查看图表用途。
- 支持当前运行的 CSV、JSON 和 SVG 导出。

这是仿真网页；结果不代表新采集的真实仪器测量数据。网页包含 Three.js，其 MIT 许可证保留在 index.html 中。

## 装配边界

装配练习按既有布局检查器件位置，不代表完成真实实验的光轴对准、波片标定、相位匹配或纠缠态制备。A / B 测量半波片在采集时的实际角度参与计数和结果计算；源端半波片、前级补偿及其他器件仍采用固定模型假设。

一对角度得到一个 E；本单通道模型每个 E 需要四次独立采集，共 16 次。四组完成后计算 `|E1−E2+E3+E4|`。四组实际角度满足 `(a,b)、(a,b′)、(a′,b)、(a′,b′)` 时，这才是 CHSH 的 `|S|`；否则仍允许采集并显示组合值 `|S*|`，但标记“非 CHSH”，不与 2 和 2√2 比较。理想模式也含泊松抽样，测量估计值不等于无噪声理论值。原理、符号约定与来源见 [PHYSICS.md](PHYSICS.md)。

- `assembly-scene.js`：安装位、模型可见性、模型缩略图、入位动画。
- `assembly-catalog.js`：器件名称、作用、位置与模型边界说明。
- `assembly.js` / `assembly.css`：器件库、引导装配、移动端布局和本地进度。
- `assembly-icons.js`：Lucide 图标节点子集，许可证见 `LUCIDE-LICENSE`。
- `measurement-core.js`：四对机械角、16 次采集计划、理论 E / S 和 CHSH 配对检查。
- `measurement-ui.js` / `measurement.css`：四组装配配置、自由角度采集与 E 记录、折叠理论值、测量互锁和输入校验。

直接用浏览器打开 `index.html` 即可，无需构建或开发服务器。装配过程和原实验都不依赖 CDN。

## 验证

在可解析 `playwright` 与 `sharp` 的 Node 环境分别运行 `node tests/assembly.test.cjs` 和 `node tests/measurement.test.cjs`。可通过 `NODE_PATH` 指定依赖目录，通过 `BROWSER_PATH` 指定 Chromium/Edge 可执行文件，通过 `QA_OUTPUT` 指定截图目录。

测试覆盖 27 件完整装配、左右计数设备与线缆布局、入射半波片镜架、错位拒绝、拆卸、重置与取消、搜索、进度恢复、三种采集模式、暂停互锁、原参考数据、桌面与手机布局及三维画布像素检查。

角度专项测试额外覆盖 300 套 CHSH 设置及 300 套独立四对角度的 Jones 振幅交叉检查、半波片两倍角、最大值与非违背设置、重复角独立采集、四组配置持久化及旧格式迁移、任意有效角度可采集、实际角度驱动计数、逐组停止、未满四组不显示 S、非 CHSH 组合的警示、组间参数锁定、暂停后重测与取消、随机种子复现以及 CSV / JSON / SVG 来源信息。
